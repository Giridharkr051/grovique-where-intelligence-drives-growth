# GROVIQUE — Product Overview & Feature Matrix

## 1. Product Identity
- **Product Name**: GROVIQUE
- **Tagline**: *Grow with clarity. Analyze with confidence.*
- **Category**: Premium Intraday Stock Market Research & Analytics Platform
- **Target Market**: Indian Equities — National Stock Exchange (NSE) & Bombay Stock Exchange (BSE)

## 2. Core Functional Modules

| Module | Core Purpose | Key User Capabilities |
| :--- | :--- | :--- |
| **1. Overview (Dashboard)** | Glanceable summary of Indian market conditions | Major index benchmarks (NIFTY 50, SENSEX, BANK NIFTY, INDIA VIX), Market Breadth (Adv/Dec), Top Gainers & Losers, High Volume stocks, Saved Presets. |
| **2. Stock Scanner** | Rules-based instrument discovery | Filter universe by price, % change, volume, RVOL, ATR, VWAP distance, EMA stacking, RSI, MACD. Side-drawer with **"Why this matched"** transparent explainability. |
| **3. Stock Detail** | Deep-dive individual equity research | High-performance Canvas Candlestick charts, multi-timeframe (`1m` to `1M`), Level-2 5-depth order book, indicator suite, company notes. |
| **4. Watchlists** | Multi-list portfolio monitoring | Create custom watchlists, real-time quote tracking, sorting, filtering, and rapid navigation to charts. |
| **5. Market Activity** | Broad-market momentum leaderboards | Turnover leaders, volume spikes, intraday gainers/losers, sector performance breakdown. |
| **6. Alerts Centre** | Informational rule triggers | Set price thresholds, volume surge alerts, VWAP crossovers. Informational push notifications without broker execution. |
| **7. Paper Journal** | Simulated hypothesis testing | Record hypothetical trades with entry, target, stop loss, research thesis, and cost/slippage friction. Clearly labelled **SIMULATED**. |
| **8. Learning Centre** | Financial literacy & technical education | In-depth explainers on VWAP, Moving Averages, RSI, MACD, ATR, Market Depth, and Stale Data. |
| **9. Investment Calculators** | Multi-asset wealth compounding | SIP with step-up, Stocks CAGR, Bank FD quarterly compounding, Bonds & SGBs, Inflation & FIRE nest-egg corpus. |
| **10. Multi-Agent Swarm** | Autonomous research team | 5-agent deliberation: Macro News Scout, Quant Analyser, Stock Picker, Risk Officer, and Lead Orchestrator. |
| **11. RAG & MCP Studio** | Gemini 2.0 AI context protocol | Semantic retrieval over institutional playbooks with Model Context Protocol tool calling. |
| **12. Settings** | System configuration | User profile, display density, default watchlist, chart intervals, and API configuration. |
